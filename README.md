# Expense Tracker

## Project Overview

The Expense Tracker is a simple Python program that allows users to enter multiple expense amounts and calculates the total amount spent.

## Objective

The main objective of this project is to understand how Python can process numerical data using variables, loops, user input, and arithmetic operations.

## Features

- Accepts multiple expense amounts from the user.
- Adds all entered expenses together.
- Allows the user to stop entering expenses by typing `done`.
- Displays the total amount spent.

## Technologies Used

- Python
- python idle

## Key Concepts

- Variables
- User input
- While loops
- If conditions
- Arithmetic operations
- Accumulators

## How It Works

The program starts with a total value of 0. Each time the user enters an expense, the amount is converted into a number and added to the total. When the user enters `done`, the program stops accepting expenses and displays the total amount spent.

## Example

Enter an expense (or type 'done' to finish): 100

Enter an expense (or type 'done' to finish): 50

Enter an expense (or type 'done' to finish): 20

Enter an expense (or type 'done' to finish): done

Total Spent: 170.0

## Conclusion

This project provides a basic understanding of how Python can be used to collect, process, and calculate numerical data. It demonstrates the use of loops and accumulators in a practical expense-tracking application.
